# 스포츠 라이브 경기 센터

한국어 중심의 정적 스포츠 경기 일정·스코어 웹사이트입니다.

- 사이트: https://ldmsrh-coder.github.io/sports-live/
- GitHub Pages에 배포되며, 브라우저에서 날짜·종목별 경기 정보를 조회합니다.
- 경기 시작 시간은 한국 표준시(KST) 기준으로 표시합니다.

## 주요 기능

- **전체 종목 보기:** 축구, 농구, 테니스, 크리켓, 야구, 아이스하키, 미식축구, 배구, 핸드볼, 배드민턴, 탁구, 럭비
- **날짜 달력:** 원하는 날짜를 선택해 경기 일정을 조회
- **검색 및 상태 필터:** 팀·리그·국가 검색, 진행 중·예정·종료 경기 필터
- **국가 표기 보정:** 제공처의 `Country Confirmation Needed`, `Country_Check_Required`, `국가 확인 필요` 등 미확정 국가 문자열을 한국어 UI에 그대로 노출하지 않음. 국가명이 미확정이어도 유효한 국가 코드가 있으면 해당 코드를 우선 사용하고, 그렇지 않으면 리그 정보를 바탕으로 보완하며 확인 근거가 없으면 `국제/기타`로 표시. 한글이 유니코드 정규화 과정에서 분해되어 탐지에 실패하던 문제를 수정하고 회귀 테스트를 추가
- **즐겨찾기:** 경기 카드의 별표를 눌러 브라우저에 즐겨찾기 저장
- **링크 공유:** 현재 날짜·종목·검색어·상태 필터를 담은 링크 복사
- **CSV 내보내기:** 현재 필터에 표시된 경기와 점수·상태·시간·출처를 CSV로 저장하며, 수식처럼 해석될 수 있는 외부 문자열은 텍스트로 이스케이프
- **경기별 출처 표시:** 각 경기 카드에 출처를 표시하고, 알려진 공식 리그·제공처는 해당 출처로 연결합니다. 출처 표시 자체가 점수의 독립 검증을 뜻하지는 않음
- **자동 갱신:** 오늘 경기는 페이지가 열려 있을 때 약 90초마다 다시 조회하며, 다른 탭에서 돌아오거나 인터넷 연결이 복구되면 즉시 다시 조회
- **자동 경기 판독실:** 경기 수, 진행·종료, 출처 기록률, 필수 항목 완성률, 승률 표시 가능 수, 국가 미확정·국제 대회, 시간 미정, 진행 경기 점수 누락을 요약합니다. 출처·대회명 누락, 예정 경기의 숫자 점수, 중복 의심을 점검하고, 점수 변경이 감지되면 이전·현재 값을 표시합니다. 브라우저에 저장된 종료 예측이 20건 이상이면 Brier 점수로 예측을 사후 평가합니다(낮을수록 좋음). 검증 표본이 부족하면 수치를 과장하지 않고 축적 중으로 표시합니다. 이 기능은 설명 가능한 규칙·통계 기반 분석이며 생성형 AI·영상 판독(VAR)·선수 추적은 아닙니다.
- **데이터 품질 요약:** 출처 기록률과 필수 필드 완성률을 따로 표시하며, 어느 쪽도 실제 정확도 확률로 표현하지 않습니다. 예정 경기의 숫자 점수, 진행 중 점수 누락, 출처·대회명 누락, 중복 의심을 자동 점검합니다. 점검 결과는 오류를 발견하기 위한 신호이며 외부 출처를 독립적으로 검증했다는 뜻은 아닙니다.
- **국내 일정 보완:** K리그, K3·K4, KBO, KBL·WKBL, V리그, 핸드볼 등 지원되는 국내 일정 데이터를 보완
- **오프라인성 보완:** 조회 결과를 브라우저에 캐시해 제공처가 일시적으로 응답하지 않을 때 일부 일정을 다시 표시

## 데이터와 정확도 안내

경기 데이터는 공개된 스포츠 데이터 제공처와 국내 리그 일정 데이터에서 가져옵니다. 제공처의 장애, API 제한, 경기 취소·연기 업데이트 지연, 대회 미등록 또는 지원 범위 차이로 인해 일부 경기가 누락되거나 갱신이 늦을 수 있습니다. 따라서 전 세계 모든 종목·대회의 전체 경기 제공을 보장하지 않습니다. 점수와 경기 상태는 가능한 경우 원본 제공처 값을 우선 사용하며, 제공되지 않는 정보는 임의로 만들어 표시하지 않는 것을 원칙으로 합니다.

일부 팀명과 리그명은 한국어 사전 및 일반 명칭 변환 규칙으로 표기합니다. 모든 고유명사의 공식 한국어 표기가 확보되는 것은 아니므로, 낯선 팀명은 원문 일부가 남을 수 있습니다.

### 승률·신뢰도 표시 원칙

- 공식 제공처의 예측값과 배당에서 환산한 값은 출처 유형을 구분합니다. 배당 환산 확률은 실제 배당 데이터가 있을 때만 사용할 수 있습니다.
- 자체 모델은 저장된 과거 경기의 Elo, 승패, 득실, 최근 흐름, 팀별 홈·원정 성적, 최근 경기 후 휴식일을 이용합니다. 양 팀의 기록이 전혀 없거나 합계 6경기 미만이면 승률을 숨깁니다. 합계 6경기 이상이지만 표본이 작은 경기는 **초기 참고용 추정**으로 표시하고 표본 제한·정확도 미검증을 함께 알립니다. 표본이 많다는 사실만으로 정확도가 검증되는 것은 아닙니다.
- 브라우저 기반 예측 검증은 해당 브라우저의 로컬 저장 데이터만 사용하므로 다른 기기·브라우저의 예측을 합산하지 않습니다. 검증 표본이 20건 미만이면 Brier 점수 대신 축적 중 상태를 보여줍니다. 모델 이력 조회는 동시에 실행되는 요청 수를 제한합니다.
- 부상·결장, 확정 선발·라인업, 경기장 날씨, 배당 변동은 검증된 데이터 연동이 없는 한 자동 반영됐다고 표시하지 않습니다. 경기별 참고 링크는 자동 수집·검증된 사실이 아니라 외부 검색 바로가기입니다.
- 경기 목록에 제공처 조회 실패를 함께 표시해, 일부 소스가 실패했는데도 전체 데이터가 정상인 것처럼 보이는 문제를 줄입니다.

### 보안·품질 점검

- 외부 새 창 링크에 noopener/noreferrer 속성을 사용하고, 페이지의 외부 참조자 정보 노출을 제한합니다.
- 애플리케이션 JavaScript를 `app.js`로 분리하고 CSP에서 인라인 스크립트를 차단합니다. 이미지 오류 처리도 인라인 이벤트 속성 대신 이벤트 리스너를 사용합니다. 인라인 스타일은 현재 디자인 구조상 허용되어 있으므로 CSP만으로 모든 XSS 위험이 제거되는 것은 아닙니다.
- CSP의 데이터·이미지 허용 목록은 실제 사용하는 제공처로 제한합니다. 새로운 데이터 제공처를 추가할 때는 CSP와 회귀 테스트도 함께 갱신해야 합니다.
- 화면의 데이터 품질 요약은 출처 메타데이터 유무를 보여주는 참고 지표이며, 데이터 제공처가 정확하다는 보증이나 독립 검증 결과를 의미하지 않습니다.
- GitHub Actions는 수집기 단위 테스트에 더해 HTML 내 JavaScript 문법과 경기 스냅샷의 필수 필드를 검사합니다.
- 이 프로젝트는 브라우저에서 외부 스포츠 API를 직접 호출합니다. 브라우저에서 공개 API를 호출하는 구조이므로 제공처 장애·CORS·호출 제한을 완전히 통제할 수는 없습니다. 비밀 API 키를 HTML에 넣지 않습니다.

## 프로젝트 구조

- `index.html`: 웹 UI, 스타일, CSP 정책
- `app.js`: 경기 조회·렌더링·국가 정규화·데이터 품질 점검
- `data/korean-sports.json`: 국내 경기 일정 스냅샷
- `scripts/update_korean_sports.py`: 국내 일정 수집 스크립트
- `scripts/test_update_korean_sports.py`: 국내 일정 수집기 테스트
- `scripts/test_country_normalization.js`: 국가 미확정 문자열·국가 코드 우선 처리 회귀 테스트
- GitHub Actions: 일정 수집 및 Pages 배포 자동화

## 로컬 점검

Python 수집기 테스트:

```bash
python -m unittest scripts/test_update_korean_sports.py
node scripts/test_country_normalization.js
```

웹 화면은 정적 HTML이므로 별도 빌드 없이 GitHub Pages에서 제공할 수 있습니다.
