# 스포츠 라이브 경기 센터

한국어 중심의 정적 스포츠 경기 일정·스코어 웹사이트입니다.

- 사이트: https://ldmsrh-coder.github.io/sports-live/
- GitHub Pages에 배포되며, 브라우저에서 날짜·종목별 경기 정보를 조회합니다.
- 경기 시작 시간은 한국 표준시(KST) 기준으로 표시합니다.

## 주요 기능

- **전체 종목 보기:** 축구, 농구, 테니스, 크리켓, 야구, 아이스하키, 미식축구, 배구, 핸드볼, 배드민턴, 탁구, 럭비
- **날짜 달력:** 원하는 날짜를 선택해 경기 일정을 조회
- **검색 및 상태 필터:** 팀·리그·국가 검색, 진행 중·예정·종료 경기 필터
- **즐겨찾기:** 경기 카드의 별표를 눌러 브라우저에 즐겨찾기 저장
- **링크 공유:** 현재 날짜·종목·검색어·상태 필터를 담은 링크 복사
- **CSV 내보내기:** 현재 필터에 표시된 경기와 점수·상태·시간·출처를 CSV로 저장
- **자동 갱신:** 오늘 경기는 페이지가 열려 있을 때 주기적으로 새로 조회
- **국내 일정 보완:** K리그, K3·K4, KBO, KBL·WKBL, V리그, 핸드볼 등 지원되는 국내 일정 데이터를 보완
- **오프라인성 보완:** 조회 결과를 브라우저에 캐시해 제공처가 일시적으로 응답하지 않을 때 일부 일정을 다시 표시

## 데이터와 정확도 안내

경기 데이터는 공개된 스포츠 데이터 제공처와 국내 리그 일정 데이터에서 가져옵니다. 제공처의 장애, API 제한, 경기 취소·연기 업데이트 지연, 대회 미등록 또는 지원 범위 차이로 인해 일부 경기가 누락되거나 갱신이 늦을 수 있습니다. 따라서 전 세계 모든 종목·대회의 전체 경기 제공을 보장하지 않습니다. 점수와 경기 상태는 가능한 경우 원본 제공처 값을 우선 사용하며, 제공되지 않는 정보는 임의로 만들어 표시하지 않는 것을 원칙으로 합니다.

일부 팀명과 리그명은 한국어 사전 및 일반 명칭 변환 규칙으로 표기합니다. 모든 고유명사의 공식 한국어 표기가 확보되는 것은 아니므로, 낯선 팀명은 원문 일부가 남을 수 있습니다.

## 프로젝트 구조

- `index.html`: 웹 UI, 필터, 경기 렌더링 및 브라우저 측 데이터 조회
- `data/korean-sports.json`: 국내 경기 일정 스냅샷
- `scripts/update_korean_sports.py`: 국내 일정 수집 스크립트
- `scripts/test_update_korean_sports.py`: 수집기 테스트
- GitHub Actions: 일정 수집 및 Pages 배포 자동화

## 로컬 점검

Python 수집기 테스트:

```bash
python -m unittest scripts/test_update_korean_sports.py
```

웹 화면은 정적 HTML이므로 별도 빌드 없이 GitHub Pages에서 제공할 수 있습니다.
